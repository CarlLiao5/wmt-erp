# ALLSKU2026 月度 SKU 目标初始化设计

## 目标

每月从已同步的 ALLSKU2026 商品表生成 SKU 级目标草稿，自动带出店铺、SKU、品名和当前负责人，并依据上月订单统计与当前库存计算预计日销、销售天数、数量目标和金额目标。管理员可以导出带公式的 Excel 调整预计日销，预览校验后回导并定版；Targets 页面继续支持管理员直接调整。

## 已确认口径

- 商品范围：当前租户最新的 ALLSKU2026 数据中，能匹配 ERP 店铺和 SKU 的行。
- 品名：优先 ALLSKU2026 品名；没有时回退 ERP 商品名称。
- 负责人：ALLSKU2026 的「当前负责人」。
- 上月销量：订单行数量按美国太平洋时间归属到上一个自然月后求和。
- 上月自然日天数：上月日历天数，作为日均销量分母。
- 上月日均销量：`上月销量 / 上月自然日天数`。
- 上月均价：`上月订单金额 / 上月销量`；销量为 0 时为空，不伪造价格。
- 在库库存：Inventory 当前最新库存快照中的可用库存数量，按店铺 + SKU 取值；没有库存快照时为空并标记数据缺失。
- 本月天数：目标月份的自然日天数。
- 销售天数：`MIN(本月天数, 在库库存 / 预计日销)`；预计日销为 0、库存缺失或任一输入无效时为 0 或空，并保留缺失原因。
- 预计日销初始值：上月日均销量。管理员可在导出的 Excel 中调整。
- 数量目标：`销售天数 * 预计日销`。
- 金额目标：`上月均价 * 数量目标`；上月均价缺失时为空。
- 目标计算保留小数，展示层可按现有目标金额格式化；不得将缺失数据显示成 0。

## 生命周期

1. 管理员选择目标月份并点击「初始化 SKU 目标」。系统以该月的上月数据生成一个 `draft` 批次；同一租户、月份已有草稿或定版批次时不重复创建，返回现有批次并提示状态。
2. 草稿包含计算输入、计算结果、公式版本和数据来源时间，作为可审阅快照，不随之后订单或库存变化自动重写。
3. 管理员导出 XLSX。数量目标和金额目标单元格写入 Excel 公式，引用同一行的预计日销、销售天数和上月均价；输入列和计算列清晰区分。
4. 管理员修改预计日销或其他允许调整字段后，上传 XLSX 进行预览和校验。校验包括必填字段、数值非负、月份一致、SKU/店铺存在、公式结果可计算，以及不允许改变系统匹配字段。
5. 预览无错误后点击提交，批次变为 `finalized`，写入正式 SKU 目标明细和店铺/月汇总。已定版批次不可被普通导入覆盖；管理员可在 Targets 页面明确编辑并生成新的修订记录。

## 数据模型

新增月度 SKU 目标明细与批次表，至少保存：`tenantId`、`batchId`、`month`、`storeId`、`sku`、`itemId`、`productName`、`ownerName`、`inventoryQuantity`、`lastMonthUnits`、`lastMonthDays`、`lastMonthAvgDailySales`、`lastMonthAvgPrice`、`expectedDailySales`、`sellingDays`、`quantityTarget`、`amountTarget`、`formulaVersion`、`status`、`sourceSnapshotAt`、`createdAt`、`updatedAt`。

批次状态使用 `draft`、`finalized`、`superseded`。正式汇总仍兼容现有 `sales_targets`，但由 SKU 明细汇总产生；现有 Dashboard 的月度目标读取继续使用统一的租户、店铺和月份口径。

## API 与权限

- `POST /api/targets/initialize`：管理员按月份创建或返回草稿批次。
- `GET /api/targets/:batchId`：读取批次、明细和缺失数据标记。
- `GET /api/targets/:batchId/export?format=xlsx`：导出带公式的草稿。
- `POST /api/targets/:batchId/preview`：上传调整后的行，返回校验结果和计算预览。
- `POST /api/targets/:batchId/finalize`：管理员提交无错误批次并定版。
- Targets 页面增加月份选择、初始化、草稿状态、导出、导入预览、定版和管理员编辑入口。

所有查询和汇总必须先按租户及当前用户的店铺 + SKU 可见范围过滤；管理员保留全量视图。普通用户不得初始化、导入、定版或编辑目标。

## Excel 约束

导出列至少包括：店铺、SKU、Item ID、品名、负责人、在库库存、上月销量、上月天数、上月日均销量、上月均价、预计日销、销售天数、数量目标、金额目标、缺失原因。数量目标公式为 `=销售天数*预计日销`，金额目标公式为 `=上月均价*数量目标`。导入时以单元格计算结果和允许编辑列为准，不把公式文本当作数据库值；系统重新计算并校验结果。

## 失败与缺失数据

- ALLSKU 无法匹配店铺或 SKU 的行不进入目标草稿，并在批次摘要中计数。
- 没有订单的 SKU 仍可进入草稿，销量、日销和均价标记为无数据，目标不伪造为 0。
- 没有库存快照的 SKU 仍可进入草稿，库存和销售天数标记为无数据。
- 上月销量为 0 时均价为空；管理员可以在 Excel 中补充允许调整的预计日销，但不能伪造上月均价来源。
- 初始化、预览、定版均记录批次和公式版本，重复请求必须幂等。

## 验收标准

- 目标月份初始化后，每个可匹配 ALLSKU SKU 有一行，品名和负责人正确。
- 上月订单、均价和当前库存按店铺 + SKU 计算，不串店铺、不使用未来订单。
- 销售天数严格受本月自然日天数上限约束。
- Excel 导出包含可编辑预计日销和可重新计算的数量/金额公式。
- 修改预计日销后预览能显示新的数量目标和金额目标，错误行不能定版。
- 定版后重复初始化不会覆盖正式结果；修订有明确批次关系。
- Targets、Dashboard 和成员权限读取同一租户/店铺/SKU 口径。
