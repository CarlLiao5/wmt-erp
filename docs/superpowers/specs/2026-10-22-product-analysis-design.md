# 商品分析页面设计

## 目标

新增一个独立的商品分析页面。用户通过 SKU、产品名称或 Item ID 搜索并选择商品，再按日期范围查看销售、退货、站内广告和 SEM 的统一分析结果。

## 页面入口与权限

- 在现有主导航增加「商品分析」入口。
- 页面沿用现有登录、租户、店铺和 SKU 可见范围。
- 普通成员只能看到其被授权的店铺 + SKU；管理员可看到全部可见商品。
- 未选择商品时显示搜索结果和空状态，不请求无商品范围的重型聚合查询。

## 筛选交互

- 商品搜索字段支持 SKU、产品名称、Item ID，输入后展示匹配商品列表，列表显示图片、SKU、产品名称、Item ID、店铺。
- 选择商品后显示已选商品摘要，并允许更换商品。
- 日期默认最近 30 天，使用现有日期范围选择器。
- 开始日期不得晚于结束日期；日期变化后由一个聚合请求刷新全页面数据。
- 加载时保留已选商品和筛选控件，内容区域使用稳定的 loading 状态，避免指标卡闪烁。

## 指标口径

后端聚合接口返回以下指标：

- 销售额：选定日期内订单行金额总和。
- 销量：选定日期内订单行数量总和。
- 退货数：选定日期内退货明细数。
- 退货率：退货订单数 / 同日期范围内出单订单数；无订单时返回 null。
- 站内广告花费：选定日期内站内广告花费总和。
- 站内广告销售比：站内广告花费 / 销售额；销售额为 0 时返回 null。
- SEM 广告花费：选定日期内 SEM 花费总和。
- SEM 广销比：SEM 花费 / 销售额；销售额为 0 时返回 null。
- 总广销比：(站内广告花费 + SEM 花费) / 销售额；销售额为 0 时返回 null。

金额统一返回数值，前端按 USD 格式化；比率返回 0-1 数值，前端显示百分比。

## 聚合接口

新增 `GET /api/product-analysis`，参数：

- `sku`：必填，商品 SKU。
- `storeId`：可选；当同一 SKU 跨店铺存在时由商品选择结果携带。
- `from`、`to`：必填，ISO 日期 `YYYY-MM-DD`。

返回结构：

```ts
{
  product: { storeId, sku, itemId, productName, imageUrl },
  range: { from, to },
  metrics: {
    sales, units, returns, returnRate,
    onsiteSpend, onsiteSalesRatio,
    semSpend, semSalesRatio, totalSalesRatio
  },
  salesTrend: Array<{ date, sales, units }>,
  adSpendTrend: Array<{ date, onsiteSpend, semSpend, totalSpend }>,
  returnTrend: Array<{ date, count }>,
  returnReasons: Array<{ reason, count }>,
  semTerms: Array<{ term, count, spend, sales }>,
  onsiteTerms: Array<{ term, count, spend, sales }>
}
```

## 图表与交互

- 销售趋势：双折线/柱线组合，分别展示销售额和销量；悬停显示日期、销售额、销量。
- 广告花费趋势：站内、SEM、总花费三条可切换曲线；图例可点击隐藏/显示系列，悬停显示精确值。
- 退货原因：交互式 SVG 扇形图，点击原因后在页面内标记选中原因并显示数量/占比；保留可键盘操作的图例。
- 退货趋势：按日期柱状图，点击某日将日期范围收窄到该日并刷新数据。
- SEM 词云、站内广告词云：高频词更大，按花费或销售额提供排序说明；点击词语显示该词的次数、花费和销售额。无词数据时显示明确空状态。
- 每个图表提供简短的数据口径说明，避免仅靠颜色传达含义。
- 图表在移动端改为单列，避免横向滚动；长 SKU 和产品名称截断时保留 title 完整提示。

## 数据来源与限制

- 订单和销量使用现有订单行标准化数据。
- 退货使用现有退货标准化数据。
- 站内广告和 SEM 使用现有广告事实/商品报告数据，并按 SKU、店铺和日期过滤。
- SEM 搜索词和站内广告词云仅在已有词项数据时展示，不伪造词项。
- 后端先应用权限和商品过滤，再计算指标和趋势，避免汇总越权。
- 不新增第三方图表依赖，复用现有 SVG、柱状图和词云渲染模式。

## 验收标准

1. 可搜索并选择授权范围内的 SKU、产品名称或 Item ID。
2. 默认最近 30 天，可自定义日期且不能提交反向日期范围。
3. 指标和趋势在同一次请求后保持一致，空数据显示“暂无数据”而非 0 的误导值。
4. 站内广告、SEM、退货和销售均按所选店铺 + SKU 过滤。
5. 图表支持悬停、键盘焦点或点击交互，且移动端不产生页面级横向滚动。
6. 管理员和普通成员的结果符合现有 SKU 可见性规则。
