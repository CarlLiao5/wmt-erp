# 商品评论抓取与查看

日期：2026-11-16

## 已确认目标

新增商品评论页面和评论抓取 Work。Firecrawl 读取 Walmart 评论页，以 Item ID 构造 `https://www.walmart.com/reviews/product/{itemId}?sort=submission-desc`。数据存入现有 Doke 数据库，页面读取本地数据，不在浏览时调用抓取服务。

用户已确认首次抓取和持续增量两种模式：首次逐页读取历史；持续增量每四天只读取按最新发布排序后的第一页，不根据最后评论时间向后翻页。

## 同步行为

首次：先取第一页，从实际返回内容提取下一页 URL 与评论，验证域名和 Item ID，逐页继续。末页、重复分页 URL、重复页面内容或配置的页面预算达到时停止。页面被拦截或解析失败应报错，不记为无评论或首次完成。每页成功后持久化进度，重试从断点继续。

增量：以每个被纳入同步的商品为单位，每四天（96小时）到期排队，仅访问最新评论排序的第一页。按评论 ID 幂等更新。若四天新增评论超过一页，仅第一页被覆盖，这是用户指定的范围；页面明确显示抓取模式和时间。

初步验证仅使用 Item ID 1201369196，最多两页。必须验证实际返回结构、评论稳定标识、分页链接和排序生效，再启用批量历史抓取。

## Firecrawl 与额度控制

使用官方 v2 batch scrape，提交有限 URL 集合并轮询任务状态；任务结果分页与 Walmart 评论分页分别处理，不能混淆。Walmart 下一页 URL 必须从抓取结果确认，不能凭假定的 page 参数提前生成全部地址。

共享 API key 的抓取并发默认1，最多2，不能因不同商品或任务并行突破上限。对429尊重 Retry-After，缺失时使用带抖动的指数退避；设置重试上限。记录任务 ID、页数、服务端实际返回的计费信息（若有），不把估算当作账户余额。页面预算可配置，达到预算保存断点并标记暂停。未确认免费套餐具体每分钟请求额度前，不宣称固定请求频率一定符合套餐。

密钥仅服务端保存，使用现有加密配置方式，响应和日志均不回显。Worker 重启后能继续跟踪已提交 batch，避免重复提交耗费额度。

## 数据与权限

配置、商品抓取目标、评论、分页检查点及任务记录存入现有 Doke 库，不创建 Docker 数据库。评论保存来源 Item ID、平台评论 ID、星级、标题、正文、日期、评论人、验证购买标记、来源 URL、首次/最近抓取时间以及原始来源数据（字段以实际页面为准）。

同 Item ID 跨店铺可能指向同一公开页面；公开评论可按租户+Item ID去重保存，查询时通过当前可见的店铺/SKU商品关联授权，不因共享评论绕过成员权限。无稳定评论 ID 时应先明确可重复计算的替代标识，再上线持久化去重。

## Work 与页面

复用 API → BullMQ → Worker → MySQL 与同步状态台账，不新增独立常驻服务。首次与增量使用不同幂等键，同商品互斥，定时计划持久化，重启不会重置四天周期。首次结束后允许启用或暂停增量，首次未完成时不并行启动同商品增量。

新增商品评论导航页面：商品图片、中文名、SKU、Item ID、评论列表及星级/日期/文字筛选、服务端分页。管理员可选择目标商品、首次抓取、继续历史、立即增量、开启/暂停四天增量；成员只读有权商品。展示抓取模式、最近成功、下次运行、页数和失败/暂停原因。

## 验证与交付

使用真实少量抓取验证两页不会重复、按最新排序和分页准确。测试覆盖去重、断点、被拦截、429退避、任务结果分页、同商品互斥、96小时调度、租户和成员权限；确认页面不直接抓取 Firecrawl。运行相关测试及前后端和 Worker 类型检查，应用迁移并重启受影响服务后验证实际 API 和页面。

## 实施前需要审阅的边界

“筛选后的第一页”按用户前文 URL 解读为 `sort=submission-desc`（最新发布）；不附加星级筛选。首次全量有预算上限，可续抓，不在第一次测试时自动启动全部商品历史抓取。暂不替用户开启全商品定时计划。

## 补充确认：手动添加与单 Item 控制

用户可由管理员手动输入 Item ID 添加抓取目标，不要求该 Item 已存在于 ERP 商品库。租户内重复添加同一 Item 返回已有目标，不重复创建或重置进度。新增目标默认关闭自动同步，添加本身不调用 Firecrawl。

每个 Item 独立提供首次抓取、继续历史、立即增量、开启/暂停每96小时增量；独立显示进度、最近成功、下次运行与错误。暂停计划只停止未来自动入队，不删除已有评论；正在处理的单页完成后停止后续翻页并保存断点。首次和增量对同一 Item 仍互斥。

未关联 ERP 商品的手动 Item 显示 Item ID 和“未关联商品”，图片/中文名称允许为空，不能伪造；管理员可查看本租户手动目标。成员仍须通过已有可见店铺/SKU商品关联授权，未关联目标不自动向成员开放。其他租户不能查看或操作。
